# Taller de Algoritmos Recursivos en Elixir

Este repositorio contiene las soluciones para el taller de programación funcional y recursividad en **Elixir**, desarrollado para la asignatura de Programación 3.

## Estructura del Proyecto

* **`P_01.exs`**: Conteo de vocales en una cadena (enfoques con y sin `String.graphemes/1`).
* **`P_02.exs`**: Búsqueda del número mayor en una lista mediante la estrategia **Divide y Vencerás**.
* **`P_03.exs`**: Verificación recursiva de potencias de $b$.
* **`P_04.exs`**: Verificación de números perfectos usando **recursividad de cola** (*Tail Recursion*).
* **`P_05.exs`**: Identificación de la cadena más larga en una lista.
* **`P_06.exs`**: Validación de números reversibles mediante operaciones puramente aritméticas.


## Ejecución de los Scripts
Cada archivo cuenta con valores por defecto (hardcoded) en sus atributos de módulo (@cadena, @numero, @lista, etc.) e imprime automáticamente los resultados en la salida estándar.

Para ejecutar cualquiera de los puntos desde PowerShell o Terminal, use el comando elixir:
elixir P_01.exs
elixir P_02.exs
elixir P_03.exs
elixir P_04.exs
elixir P_05.exs
elixir P_06.exs

Nota: Para probar los ejercicios de forma interactiva, también se pueden cargar los módulos mediante iex.bat Windows PowerShell.
